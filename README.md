# cpp-class-template
A simple C++ program demonstrating class templates using a single generic class to store and display different data types such as int, float, and char.

# Class Template in C++

## Concepts Used
- Class Template
- Generic Programming
- Data Types (int, float, char)
- Class and Object

## Data Types Used
- Integer: 10
- Float: 5.5
- Character: A

## Output
Value=10
Value=5.5
Value=A
